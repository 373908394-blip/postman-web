# Postman Web · 产品需求文档（PRD）

> 一句话定位：**跑在浏览器里的 HTTP API 调试客户端**，无需安装，打开网页就能构造请求、查看响应、管理集合与环境，数据保存在本机。

- 版本：v1.0（MVP）
- 目标用户：前后端开发、测试、接口联调人员
- 形态：单页 Web 应用（SPA），纯静态部署（GitHub Pages）
- 技术栈：Vite + React 18 + TypeScript + MUI v5 + Tailwind CSS + Zustand
- 持久化：浏览器 localStorage（无后端数据库）

---

## 1. 产品目标

1. **零安装可用**：任何有浏览器的机器打开链接即可发请求，不依赖桌面客户端。
2. **覆盖日常调试 80% 场景**：方法/URL/Params/Headers/Body/Auth + 响应三视图。
3. **可积累**：请求集合、环境变量、历史记录本地持久化，越用越顺手。

## 3. 功能清单（按优先级）

### P0 · MVP 必须具备

**3.1 请求构建器**
- 方法：GET / POST / PUT / PATCH / DELETE / HEAD / OPTIONS（按方法着色）
- URL 输入：支持 `{{变量}}` 插值，下方实时预览最终地址，变量缺失时红字提示
- Params：键值对表格，可启用/禁用、带描述列，自动拼进 query string
- Headers：同上，支持描述
- Body：
  - `none`
  - `form-data`（文本 + 文件，文件以 base64 持久化，>2MB 提示风险）
  - `x-www-form-urlencoded`
  - `raw`：JSON / Text / XML（JSON 支持一键格式化）
- Auth：No Auth / Bearer Token / Basic Auth / API Key（Header 或 Query）
- 一键复制等价 cURL 命令

**3.2 发送与响应**
- 发送按钮 + `Cmd/Ctrl + Enter` 快捷键，发送中显示 loading
- 响应元信息：状态码（语义色）、耗时、响应大小、是否截断
- 响应体三视图：Pretty（JSON 高亮）/ Raw / Preview（HTML iframe）
- 响应头表格、Set-Cookie 面板
- 复制响应体、换行开关
- 错误提示：超时 / CORS / 网络不可达 / 代理失败，给出排查建议

**3.3 集合（Collections）**
- 新建 / 重命名 / 删除集合
- 保存当前请求到集合、更新已保存请求、复制请求
- 点击集合内请求 → 在新标签页打开

**3.4 多标签页**
- 每个标签独立的请求与响应；新建 / 关闭 / 切换；`Cmd/Ctrl + T`、`Cmd/Ctrl + W`
- 标签状态持久化（响应体不落盘，避免撑爆 localStorage）

**3.5 环境变量**
- 多环境管理（新建 / 重命名 / 删除 / 激活）
- 变量键值表，支持启用/禁用
- 顶部环境选择器，切换后所有 `{{var}}` 立即生效

**3.6 历史记录**
- 自动记录每次发送（方法、URL、状态、耗时、时间）
- 点击重发、单条删除、清空（最多保留 200 条，同方法同地址合并）

**3.7 设置**
- 主题：浅色 / 深色 / 跟随系统
- 字号：小 / 中 / 大；响应体自动换行
- 超时时间、响应体展示上限
- 代理开关 + 代理地址
- 数据导出 / 导入 / 清空

### P1 · 增强（本期已部分实现）
- 请求集合 JSON 导入导出 — 本期做自有格式备份
- 请求头自动补全（Accept / Content-Type）
- 响应体搜索

### P2 · 后续规划

## 4. 关键约束与设计决策

| 问题 | 决策 |
|------|------|
| 浏览器 CORS | 默认直连 fetch；设置里可切换「代理模式」，请求转发到可配置代理（仓库自带 `server/proxy.js`，Express 实现，透传 body/headers） |
| 静态部署 | `base: './'`，产物为纯静态文件，GitHub Actions 自动构建并发布到 Pages |
| 数据存储 | localStorage，key 前缀 `pmweb:`；响应体与 loading 状态不入库 |
| 文件上传 | 转 base64 dataURL 存储，发送时还原为 Blob，兼容直连与代理 |
| JSON 高亮 | 自写词法分析器（`utils/jsonHighlight.ts`），不引入第三方 viewer |
| 状态管理 | Zustand + persist，按领域拆 6 个 store |

```
│          │ Body(Pretty/Raw/Preview) / Headers  │
└──────────┴────────────────────────────────────┘
```

## 6. 验收标准（Definition of Done）

1. `npm run build` 零错误产出 `dist/`。
2. 新用户打开页面即有示例集合与默认环境，可立即发出第一个请求。
3. 刷新页面后：标签、集合、历史、环境变量、设置全部保留。
4. 发送 GET `https://jsonplaceholder.typicode.com/posts?_limit=10` 能拿到 200 与 JSON 高亮结果。
5. 开启代理后，同样的请求经 `http://localhost:8787/proxy` 成功返回。
6. 推送 main 分支后 GitHub Actions 自动构建并发布到 Pages，页面可访问。
